🌌 Welcome to Illacme Plenipes: Global Private Publishing House

Illacme Plenipes is an industrial-grade AI-native global publishing engine designed for individual creators and professional publishing teams. It seamlessly transforms your local Markdown folders (Obsidian, Logseq, Typora, etc.) into a fully functional "Global Private Publishing House."

From original manuscript creation to multi-language translation, from visual binding to one-click distribution across 23 global channels, creators retain complete data physical sovereignty.

🏛️ Four Core Sovereignty Pillars

1. 🛡️ Brand Sovereignty (Imprint Sovereignty)

Each publishing project operates as an independent brand (Imprint), featuring physically isolated configurations, themes, compute resources, and distribution channels. The default brand (currently displayed) enjoys full Advanced Professional Edition privileges and serves as a fully functional testbed.

2. 🧠 Compute Slicing & Paragraph-Level Shadow Cache

  • Zero Token Waste: Intelligent hash verification and BlockShadowCache ensure zero compute consumption for unchanged paragraphs.
  • 29+ Compute Unification: Seamless switching between local models (Ollama / LMStudio) and cloud models (OpenAI / Gemini / DeepSeek / Baidu Qianfan / xAI).

3. 🎭 Multi-Framework Binding Themes (SSG Bindery)

One-click binding to six major modern static site generators:
- Sovereign (Default): Cyber frosted glass, dark neon, and minimalist tech aesthetics.
- Docusaurus / Starlight / VitePress / Nextra / Hugo: Seamless switching across the entire ecosystem of static sites.

4. 🛰️ Global Distribution Matrix (The Matrix)

  • 11 Hosting Platforms: GitHub Pages, Vercel, Cloudflare Pages, Netlify, Railway, and more.
  • 12 Distribution Channels: Dev.to, Medium, Hashnode, WeChat Official Accounts, Zhihu, Juejin, Ghost, WordPress, and more.
