🛠️ Core Secure Processing Components

1. 📷 EXIF Privacy Geolocation Desensitization (EXIF Scrubber)

Before synchronizing and uploading accompanying images from local notes to a cloud image hosting service or social media platforms:
* Automatically strip GPS latitude/longitude coordinates, home address of the shooting location, and altitude contained in images;
* Clean metadata such as camera serial numbers, lens models, author names, and timestamp of capture;
* Re-compress and optimize WebP/PNG formats, balancing image quality with loading speed.

2. 🛡️ Sensitive Word Filtering & Content Processing (Content Masker)

  • Before manuscripts are pushed to public distribution channels, the system's built-in text cleaner automatically identifies and desensitizes content based on a sensitive word dictionary set by the creator;
  • Protect critical information such as private email addresses, internal server IPs, and creator aliases from being accidentally distributed to the public internet.

3. ⚖️ Repository Compliance Gatekeeper (ContractGuard)

  • Strictly enforce physical-level isolation audits, prohibiting any build artifacts, temporary files, or logs from remaining in the theme master directory;
  • Rigorously audit the configuration layer; if plaintext keys or passwords are mistakenly entered into public configuration files, the system will trigger a security alert and block the action to ensure data sovereignty remains uncompromised.
