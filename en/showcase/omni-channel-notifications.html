🛠️ Core Mechanisms and Battle Report Content

1. 🤖 Interactive Markdown Message Cards

The notification center natively adapts rich-text formats for different platforms:
* Lark / DingTalk / WeCom: Rendered as high-end dark/light mode Markdown interactive cards, featuring highlighted status tags and a clickable "View Online Draft" button;
* Telegram / Discord: Elegant Embed embedded messages, real-time accompanied by OpenGraph cover previews and word count statistics;
* SMTP Email: Beautifully typeset HTML publishing reports, suitable for team distribution and weekly archiving.

2. 📋 What Information Does the Panoramic Publishing Battle Report Include?

Upon completion of each publishing task, the battle report automatically aggregates the following key metrics:
* ⏱️ Execution Performance: AST parsing duration, AI paragraph translation duration, static SSG compilation duration, and total distribution duration;
* 🎯 Channel Distribution Matrix: List of successfully distributed channels (e.g., GitHub Pages ✅, Netlify ✅, Xiaohongshu ✅, CSDN ✅, Medium ✅);
* 🔗 Online Permanent Links: Aggregated direct links to the latest articles generated on each platform, facilitating one-click sharing or review by creators;
* 🚨 Exception and Circuit Breaker Capture: If a channel fails due to token expiration or rate limiting, the battle report will highlight an alert and provide one-click repair suggestions.

3. 🧪 One-Click Connectivity Test in Plugin Center

After configuring any notification channel in the Governance Center's "Plugin Center", click the "🧪 Quick Test" button to send a beautifully formatted handshake probe message to the corresponding channel within 500 milliseconds, ensuring that the notification pipeline remains unobstructed.
