1. 🔒 43210 Physical Singleton Lock (Singleton Process Lock)

  • Upon system startup, the system first attempts to create an exclusive Socket binding on 127.0.0.1:43210;
  • If the port is already occupied, the system immediately intercepts secondary startups and provides a clear prompt, physically eliminating fingerprint ledger corruption and SQLite file write deadlocks caused by background multi-process competition.

2. 🔌 43212 FastAPI Governance Gateway and Physical Isolation

  • Responsible for hosting all RESTful APIs and real-time WebSocket broadcasts for the entire-site governance center (Dashboard);
  • Strictly physically isolated from the local preview service (43213), ensuring that even when static sites are compiling or refreshing, operations of the governance center and telemetry metric collection are not blocked.

3. 🛡️ Exception Circuit-Breaking and Health Self-Healing (Resilience & Fault-Tolerance)

  • AI Compute Timeout Circuit-Breaker: When cloud large model interfaces or local Ollama encounter network hangs, the self-healing gateway automatically triggers timeout protection and degrades to paragraph shadow cache or backup compute pipelines;
  • Non-Interactive Subprocess Protection: All background external CLI calls are forcibly appended with --yes / -y and non-interactive flags, completely avoiding backend hangs caused by waiting for user input.
