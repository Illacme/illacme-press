⚡ Creator's 5-Minute Quick Start Guide

Welcome to Illacme Plenipes! Follow these five simple steps to experience the end-to-end workflow from creation to global publication in just a few minutes.

🛠️ Step 1: Launch the Publishing Command Center

Run the following command in your terminal to wake up the system:

# 启动出版指挥中心与治理面板
python3 plenipes.py

The terminal will print an elegant ASCII publishing badge and automatically start the Web API control gateway (port 43212) and the Governance Center.

🎛️ Step 2: Enter the Governance Dashboard (Governance Center)

Open your browser and visit:
👉 http://127.0.0.1:43212/dashboard/

Within the Governance Center, you can intuitively experience:
1. Basic Configuration & Operations: View brand identity, storage adaptation, and compute cache clearing hub.
2. Layout Binding & Modes: Switch brands, configure themes, and set publishing modes (Basic / Enhanced / Global).
3. Language Translation & Governance: Configure multi-language matrix, block-level filtering rules, and terminology glossaries.
4. Distribution Routing & URL Paths: Configure folder-to-URL path mapping matrices.

💡 The default brand (Illacme Press) has all Advanced Professional Edition features unlocked by default; you are free to try every configuration option!

✍️ Step 3: Draft Manuscripts in the Local Vault

Your manuscripts are securely stored in the ./vault folder. You can use your preferred Markdown editor (such as Obsidian):

  • Create a new file named my-note.md under ./vault/Blog/
  • Fill in standard Markdown headings and body text
---
title: 我的第一篇主权笔记
date: 2026-08-16
tags: [HelloWorld, Note]
---

# 🚀 记录我的最新思考

这是我在 Illacme Plenipes 中撰写的第一篇原稿！

🚀 Step 4: One-Click Global Publishing and Translation

Trigger publishing via either of the following methods:
1. GUI: Click the 🚀 Publish Globally button in the top-right corner of the Governance Center.
2. CLI: Run python3 plenipes.py --sync to execute a single full synchronization.

The system will automatically perform:
- Incremental paragraph slicing and hash computation (zero token consumption for unmodified sections)
- Multi-language polishing and translation at the compute center
- AI SEO structured metadata extraction
- Static site HTML artifact rendering

🌐 Step 5: Preview Published Output Locally

After synchronization completes, access the local preview service:
👉 http://127.0.0.1:43213/

You will see a modernized site elegantly bound with the Sovereign cyber theme, featuring bilingual Chinese-English switching, dynamic directory, instant search, and responsive layout!
