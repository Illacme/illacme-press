🧠 Compute Center & AI Translation Configuration Guide

Illacme Plenipes features the industry-leading AI Compute Unified Gateway. Whether deploying open-source small models locally or utilizing top-tier closed-source large models in the cloud, both can be seamlessly integrated into the publishing pipeline via a unified protocol.

🚀 Core Working Principle: Paragraph-Level Shadow Cache (BlockShadowCache)

Traditional full-document translation re-invokes the LLM for every minor modification, resulting in massive token waste. Illacme Plenipes employs semantic paragraph sharding:

  1. Precise Slicing: The Markdown parser decomposes documents into independent semantic blocks such as headings, paragraphs, code blocks, quotes, and tables.
  2. Fingerprint Verification: Each block computes a SHA-256 structural fingerprint.
  3. Shadow Cache Reuse: Translated paragraphs are read instantly from the SQLite shadow database, triggering AI calls only for individual changed paragraphs.
  4. Save 90%+ Compute Power: Drastically reduces API bills and significantly shortens incremental sync wait times.

🛠️ Local and Cloud Node Configuration Examples

Configure primary and backup nodes in the Governance Center or within config.yaml / config.imprint.yaml:

translation:
  enable_ai: true
  primary_node: lmstudio_local    # 主用算力节点
  primary_model: qwen/qwen3.5-9b  # 主用模型名称
  fallback_node: ollama_local     # 备用容灾节点
  fallback_model: qwen/qwen3.5-9b # 备用模型名称
  temperature: 0.2                # 翻译温度（推荐 0.1 ~ 0.3）
  max_tokens: 4096                # 最大输出 Token

🛡️ Industrial-Grade Fault Tolerance and Self-Healing Mechanisms

  • Exponential Backoff Retry: Automatically retries with exponential backoff upon encountering 429 rate limits or transient network interruptions.
  • Automatic Failover: Automatically switches to a backup disaster recovery node when the primary node fails consecutively.
  • Pure Placeholder Bypass (Mask Bypass): Pure code, formulas, and tag blocks are automatically identified and skipped during model inference, ensuring 100% elimination of hallucinations.
