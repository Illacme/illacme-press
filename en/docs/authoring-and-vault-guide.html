✍️ Manuscript Repository Organization and Writing Guidelines

Illacme Plenipes adheres to the principle of "Manuscript as Sovereignty." The system treats your physical folder as the authoritative source (Single Source of Truth), allowing you to enjoy an industrial-grade publishing experience without abandoning your existing writing habits or note-taking software.

📂 1. Best Practices for Library Directory Structure

The system recommends a typical vault structure as follows (using ./vault as an example):

vault/
├── index.md

# Site homepage (or welcome page)

├── about.md

# Brand / Personal About page

├── Docs/

# Technical documentation / Tutorials / Knowledge base

│   ├── index.md

# Documentation hub index

│   ├── quick-start.md

# Quick start guide

│   └── ...
├── Blog/

# Blog posts / Essays / Updates

│   ├── my-first-post.md
│   └── ...
├── Showcase/

# Portfolio showcase / Works collection

│   └── index.md
└── assets/

# Local images / Attachment resources

    └── cover.png

💡 Directory as Channel: Through the Distribution Router and URL Path settings (route_matrix) in the Governance Center, you can freely map any local folder to an online URL path (e.g., mapping Docs/ to /docs/, and Blog/ to /blog/).

🏷️ 2. Frontmatter Metadata Standards

Each Markdown note is recommended to include standard YAML Frontmatter at the top for precise control over article titles, authors, dates, categories, and SEO information:

---
title: 我的技术深度解析                 # [必填] 文章标题
date: 2026-08-16                    # [推荐] 发布日期 (YYYY-MM-DD)
author: 极客创作者                   # [可选] 作者署名（留空则继承全域默认作者）
description: 一句话概述本文核心内容   # [推荐] 供 SEO 与卡片预览使用的摘要
tags: [Architecture, AI, Python]    # [可选] 标签列表，自动生成聚合标签页
categories: [Tech]                  # [可选] 分类列表
slug: deep-dive-tech                # [可选] 自定义线上 URL 后缀（留空自动生成）
draft: false                        # [可选] 设为 true 则仅在本地保存，不执行线上分发
---

🔗 3. Linking & Media Asset References

3.1 Bidirectional Links (WikiLinks)

The system fully supports Obsidian-style bidirectional links:
- Standard Link: [quick-start](../docs/quick-start.html) → Automatically resolves and links to the corresponding online HTML for quick-start.md.
- Custom Aliases: [⚡ 5 分钟上手](../docs/quick-start.html) → Renders as a hyperlink with the display alias.

3.2 Images and Attachment Resources

  • Relative Path References: ![Article Cover](./assets/cover.png)
  • Absolute/Global Paths: ![Logo](/static/logo.png)
  • Automatic Alt Text & WebP Compression: The engine features a built-in image processing pipeline that automatically converts large images losslessly to the modern WebP format and generates multi-language accessibility descriptions via AI when Alt text is missing.

⚙️ 4. Line Break Modes & Dialect Sensing

In the Governance Center under [Basic Configuration & Operations] → [Storage Adaptation], you can select based on your writing software preferences:

  1. 📄 Standard Mode (CommonMark): Single line breaks are preserved as space streams; only consecutive double line breaks (empty lines) create paragraph separation. Ideal for technical professionals accustomed to standard Markdown syntax.
  2. ✍️ Intuitive Mode (GFM Hard Line Breaks): Pressing the Enter key directly creates a new line (what you see is what you get). Suitable for daily note-taking or users accustomed to Typora / WeChat layout styles.

🔄 5. How to Integrate with Existing Vaults (Obsidian / Logseq)

If you already have a structured Obsidian knowledge base:
1. Open the Governance Center [Brand Design & Mode] → [Brand Management];
2. Click «➕ Create New Publishing Brand»;
3. Point the Manuscript Library Path (vault_root) to the absolute path of your physical notes directory (e.g., /Users/username/Documents/ObsidianVault);
4. Select the design theme and distribution channel, then click Save to instantly activate your exclusive digital publishing house!
