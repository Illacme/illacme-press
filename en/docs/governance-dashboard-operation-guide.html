🎛️ Governance Dashboard Operation Guide

The Governance Center serves as the visual control tower for Illacme Plenipes. Featuring a modern, premium frosted glass design system, it provides creators with a comprehensive hub for publishing operations and maintenance.

🧭 Four Core Category Navigation

The Governance Center is structured into four top-level categories, each equipped with secondary sub-tabs:

Governance Dashboard (治理中心)
├── 1. General Configuration & Operations (General)
│   ├── 🏷️ Identity (identity)
│   ├── 📖 Compliance (compliance)
│   ├── 📂 Storage Adaptation (storage)
│   └── ⚙️ Engine Runtime (engine)
├── 2. Brand Layout & Modes (Layout)
│   ├── 🏷️ Imprint Management (imprints)
│   ├── 🎭 Themes (themes)
│   └── 📋 Publishing Modes (modes)
├── 3. Localization & Governance (Localization)
│   ├── 🌍 Language Matrix (localization)
│   ├── 🧱 Block Rules (block_rules)
│   ├── 📖 Glossary (glossary)
│   └── 🎭 Translation Style (translation_style)
└── 4. Dissemination Routing & URLs (Dissemination)
    ├── 📝 Slug Settings (slug_settings)
    └── 🧭 Route Matrix (route_matrix)

1. General Configuration & Operations

  • 🏷️ Identity: Configure brand name (imprint_name), brand description, site logo path, and copyright information.
  • 📖 Compliance: Uniformly configure default Frontmatter author, license type (e.g., CC BY-NC 4.0), and metadata cleaning rules.
  • 📂 Storage: Physical library path (vault_root), original manuscript line break mode (hard breaks / soft breaks), and the Block Cache Hub for paragraph cache governance, along with automatic cleanup strategies for compute caches (Janitor GC / LRU).
  • ⚙️ Engine: Adjust log levels, global proxy settings, network timeouts, and telemetry collection capacity limits.

2. Brand Layout & Publishing Modes

  • 🏷️ Imprints: Overview of all independent publishing brands; supports one-click switching of the currently active publishing brand.
  • 🎭 Themes: Freely switch site binding styles (Sovereign, Docusaurus, Starlight, VitePress, Nextra, Hugo).
  • 📋 Modes:
  • Basic: Pure physical copy distribution with zero AI compute overhead.
  • Enhanced: Native language AI polishing and intelligent SEO enhancement.
  • Global: Full-scale multilingual matrix translation and global multi-channel distribution.

3. Localization & Content Governance

  • 🌍 Localization Matrix: Check or add target translation languages (50+ including English, Japanese, German, French, Spanish).
  • 🧱 Block Rules: Set precise "Translate / Bypass / Mask" strategies for code blocks, tables, Callouts, and HTML tags.
  • 📖 Glossary: Maintain a professional terminology vocabulary to ensure 100% accuracy and consistency of proper nouns across multi-language translations.
  • 🎭 Translation Style: Customize the translation tone specific to each channel (e.g., technical rigor, literary narrative, humorous wit).

4. Dissemination & Routing

  • 📝 Slug Settings: Configure AI Slug generation modes (Flat / Hierarchical) to automatically generate English URLs compliant with SEO standards.
  • 🧭 Route Matrix: Map local subfolders (e.g., Blog, Docs) to the corresponding URL prefixes of the frontend site (e.g., /blog/, /docs/).
📝 All configuration saves in the Governance Center are updated with millisecond-level hot updates, taking effect immediately upon the next synchronization.
