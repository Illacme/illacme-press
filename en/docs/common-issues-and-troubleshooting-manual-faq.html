❓ Common Issues & Troubleshooting Guide (FAQ)

This manual compiles high-frequency questions and self-healing solutions for creators during their initial setup and daily publishing processes.

🔌 Port & Service Planning

The system defaults to occupying the following 4 standard ports. Please ensure they are not conflicting with other applications:

Port Responsibility Description
43210 🔒 Singleton Process Lock: Prevents background re-starts that could corrupt the fingerprint ledger
43212 🔌 API Control Gateway: Hosts the FastAPI backend service and governance center frontend
43211 🧙 Initialization Wizard: Port for the initial configuration guide wizard
43213 🌐 Local Preview Service: Embedded static site preview server after synchronization completion

❓ Frequently Asked Questions

Q1: What is the difference between the default imprint and a custom imprint?

A: The default imprint (imprints/default) serves as the system's official showcase. When using the default imprint paired with the default Sovereign theme, the system unlocks all Advanced Professional Edition features by default, allowing users to experience the full capabilities of the platform; whereas when you create a new custom publishing imprint, features will adhere to the Community Edition and commercial licensing plans.

Q2: Why are AI Tokens not being consumed again after modifying the source manuscript?

A: The system includes built-in Block-level Shadow Cache (BlockShadowCache). During each synchronization, a fingerprint is calculated for every paragraph in the document. Unchanged paragraphs are read instantly from local cache, while only truly modified paragraphs trigger AI translation calls.

Q3: How to clear the cache or force a full recompilation?

A:
- Command Line: Run python3 plenipes.py --sync --force to force recompilation.
- Governance Center: Navigate to "Basic Configuration" → "Storage Adapter" → Click "🧹 Execute Full Cache Cleanup (GC) Now".

Q4: What should I do if local models (Ollama / LMStudio) return a 400 error or hang?

A:
1. Check if the local model service is running (e.g., LMStudio Local Server is enabled).
2. Increase max_tokens appropriately in the Governance Center (recommended $\ge 4096$) to ensure sufficient space for the local model's Thinking Process output.

🆘 Seeking More Support

If you encounter any issues not listed above, you can check the Tower and Health Radar for real-time diagnostics in the Governance Center sidebar, or submit an Issue on GitHub.
