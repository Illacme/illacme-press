🎨 Themes & Binding: Visual Customization

In Illacme Plenipes, a single source manuscript repository can be freely bound into modern static sites with different framework styles.

🎭 Six SSG Theme Matrix

Theme Name Core Technology Use Cases & Visual Style
Sovereign (Default) Native HTML5 / CSS3 / ES Modules Default flagship Cyber Glassmorphism, Dark Neon, Minimalist Tech, Zero Node.js dependency for instant output
Docusaurus React / Meta Docusaurus v3 Large-scale multilingual technical documentation repositories, Knowledge Centers, API Developer Portals
Starlight Astro / Tailwind CSS Ultra-fast lightweight technical documentation, Modern minimalist typesetting, Perfect SEO structure
VitePress Vue 3 / Vite Elegant and clean technical writing, Ultra-fast build and development experience
Nextra Next.js / React Modern blogs and comprehensive documentation sites, Highly flexible
Hugo Go / Hugo Extremely high-concurrency massive manuscript repositories with millisecond-level ultra-fast builds

✨ Sovereign Default Theme Features

The Sovereign theme is the system's native flagship binding:

  1. Cyber Glassmorphism: Premium semi-transparent frosted texture with dynamic breathing neon projections.
  2. Zero-Compilation Direct Output: Bypasses the cumbersome Node.js npm build compilation chain; the Python core directly synthesizes fully functional static HTML in milliseconds.
  3. One-Click Multi-Language Switching: Native top dropdown menu for real-time, no-refresh route alignment.
  4. Instant Physical Search: Ultra-fast full-text retrieval based on an in-memory inverted index running entirely in the frontend.
  5. Dynamic Table of Contents and Reading Progress Bar: Right-side dynamically highlighted TOC with a breathing-style scrolling progress bar at the top.

🛠️ Theme Options Customization

Fine-tune visual parameters in themes/default/theme.options.json or via the Governance Dashboard:

{
  "site_name": "Illacme Press",
  "accent_color": "#00f5ff",
  "font_family": "Outfit, sans-serif",
  "enable_glassmorphism": true,
  "enable_dark_mode": true,
  "hero_title": "Illacme Press",
  "hero_subtitle": "您的全球私人出版社。从灵感到全渠道分发，一键触达。"
}
