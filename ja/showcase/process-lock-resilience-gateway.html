1. 🔒 43210 物理単一インスタンスロック（Singleton Process Lock）

  • システム起動時にまず 127.0.0.1:43210 で排他ソケットバインディングを試みます；
  • ポートが既に使用されている場合、システムは即座に 2 回目の起動をブロックし、明確な警告を表示します。これにより、バックグラウンドでのマルチプロセス競合によるフィンガープリント帳簿の破損と SQLite ファイルへの書き込みデッドロックを物理的に根絶しています。

2. 🔌 43212 FastAPI 管理ゲートウェイと物理的隔離

  • 全站管理センター（ダッシュボード）のすべての RESTful API とリアルタイム WebSocket ブロードキャストを担当します；
  • ローカルプレビューサービス（43213）とは厳密に物理的に隔離されており、静的サイトのコンパイルやリフレッシュ時でも管理センターの操作とテレメトリ指標収集がブロックされることはありません。

3. 🛡️ 異常フェイルオーバーとヘルスチェックによる自己修復（Resilience & Fault-Tolerance）

  • AI 計算リソースタイムアウトフェイルオーバー：クラウド大規模モデルインターフェースやローカル Ollama でネットワークがハングした場合、自己修復ゲートウェイは自動的にタイムアウト保護をトリガーし、段落シャドウキャッシュまたは代替計算パイプラインへデグラードします；
  • 非対話サブプロセス保護：すべてのバックグラウンド外部 CLI 呼び出しには --yes / -y および非対話フラグを強制追加し、ユーザー入力を待機してバックグラウンドがハングするのを完全に防ぎます。
