🛠️ 核心メカニズムと戦報内容

1. 🤖 インタラクティブな Markdown メッセージカード

通知センターは各プラットフォームにネイティブ対応したリッチテキスト形式を適用します：
* 飛書 / 釘釘 / 企業微信：ハイライトされたステータスタグとクリック可能な「オンライン原稿を一覧」ボタンを含む、高級感のあるダーク/ライトモードの Markdown インタラクティブカードとしてレンダリングされます；
* Telegram / Discord：OpenGraph カバープレビューと文字数統計をリアルタイムで付帯する、洗練された Embed 埋め込みメッセージとして表示されます；
* SMTP メール：チームへの抄送や週次アーカイブに適した、美しくレイアウトされた HTML 出版レポートです。

2. 📋 パンoramik な出版戦報にはどのような情報が含まれますか？

各回の実行タスクが完了すると、戦報は以下の主要指標を自動的に集約します：
* ⏱️ 実行パフォーマンス：AST パース処理時間、AI セグメント翻訳時間、静的 SSG コンパイル時間、および配信全体の所要時間；
* 🎯 チャンネル配信マトリックス：成功した配信チャンネルのリスト（例：GitHub Pages ✅, Netlify ✅, 小红书 ✅, CSDN ✅, Medium ✅）；
* 🔗 オンライン永続リンク：クリエイターがワンクリックで共有または確認できるよう、各プラットフォームで生成された最新記事への直接リンクを統合します；
* 🚨 エラーおよびサーキットブレーカーの検出：特定のチャンネルでトークン期限切れやレート制限により配信に失敗した場合、戦報はアラートをハイライト表示し、ワンクリック修復提案を提供します。

3. 🧪 プラグインセンターによるワンクリック接続性テスト

「プラグインセンター」という管理センターで任意の通知チャネルを設定した後、「🧪 快速测试（クイックテスト）」ボタンをクリックすると、500 ミリ秒以内に該当するチャネルに美しいハンドシェイクプローブメッセージを送信でき、通知パイプラインが常に滞りなく動作していることを確認できます。
