✍️ 原稿ライブラリの組織と執筆ガイドライン

Illacme Plenipes は「原稿こそが主権」という原則を堅持します。システムは物理フォルダーを唯一の真実（Single Source of Truth）として扱い、既存の執筆習慣やノートアプリを放棄することなく、工業レベルの出版体験をお楽しみいただけます。

📂 1. 文庫ディレクトリ構造のベストプラクティス

システムが推奨する典型的なライブラリ構造は以下の通りです（例：./vault）。

vault/
├── index.md

# サイトのホーム（またはウェルカムページ）

├── about.md

# ブランド／個人の概要ページ

├── Docs/

# 技術ドキュメント／チュートリアル／ナレッジベース

│   ├── index.md

# ドキュメントセンターのインデックス

│   ├── quick-start.md

# クイックスタート

│   └── ...
├── Blog/

# ブログ記事／随想／ニュース

│   ├── my-first-post.md
│   └── ...
├── Showcase/

# 成果展示ホール／ポートフォリオ

│   └── index.md
└── assets/

# ローカル画像／添付リソース

    └── cover.png

💡 目次はチャンネル：ガバナンスセンター内の【配信ルートと URL パス】（route_matrix）を通じて、任意のローカルフォルダをオンライン URL パスに自由にマッピングできます（例：Docs/ を /docs/ に、Blog/ を /blog/ に）。

🏷️ 2. Frontmatter メタデータ規格

各 Markdown ノートの上部には、記事のタイトル、著者、日付、カテゴリ、SEO 情報を細かく制御するために標準 YAML Frontmatter を添付することを推奨します：

---
title: 我的技术深度解析                 # [必填] 文章标题
date: 2026-08-16                    # [推荐] 发布日期 (YYYY-MM-DD)
author: 极客创作者                   # [可选] 作者署名（留空则继承全域默认作者）
description: 一句话概述本文核心内容   # [推荐] 供 SEO 与卡片预览使用的摘要
tags: [Architecture, AI, Python]    # [可选] 标签列表，自动生成聚合标签页
categories: [Tech]                  # [可选] 分类列表
slug: deep-dive-tech                # [可选] 自定义线上 URL 后缀（留空自动生成）
draft: false                        # [可选] 设为 true 则仅在本地保存，不执行线上分发
---

🔗 3. リンクとメディア資産の参照

3.1 双方向リンク（WikiLinks）

システムは Obsidian スタイルの双方向リンクを完全に互換性があります：
- 標準リンク：[quick-start](../docs/quick-start.html) → 自動的に解析され、対応するオンライン HTML の quick-start.md にリンクされます。
- カスタムエイリアス：[⚡ 5 分間でのスタート](../docs/quick-start.html) → 表示エイリアスが設定されたハイパーリンクとしてレンダリングされます。

3.2 画像と添付ファイルリソース

  • 相対パス参照：![記事表紙](./assets/cover.png)
  • 絶対/全域パス：![ロゴ](/static/logo.png)
  • 自動 Alt テキストと WebP 圧縮：エンジン内蔵の画像処理パイプラインにより、大画像を自動的に無損で現代的な WebP 形式に変換し、Alt が欠落している場合は AI が文脈に基づいて多言語のアクセシビリティ対応説明を自動生成します。

⚙️ 4. 改行モードと方言適応（Dialect Sensing）

ガバナンスセンターの【基本設定と運用】→【ストレージ適応】から、執筆ソフトウェアの好みに合わせて選択できます：

  1. 📄 標準モード（CommonMark）：単一の改行符はスペースストリームとして保持され、連続した 2 つの改行（空行）で段落が区切られます。標準的な Markdown 構文に慣れた技術者向けです。
  2. ✍️ 直感モード（GFM ハード改行）：Enter キーを 1 回押すだけで即座に改行されます（所见即所得）。日常のノート作成や、Typora / WeChat のレイアウトに慣れたユーザー向けです。

🔄 5. 既存の文庫への接続方法（Obsidian / Logseq）

既存の体系的な Obsidian 知識ベースをお持ちの場合：
1. ガバナンスセンターの【ブランド装飾とモード】→【ブランド管理】を開く；
2. 「➕ 新しい出版ブランド」をクリックする；
3. 原稿ライブラリパス (vault_root) を、物理的なノートディレクトリの絶対パス（例：/Users/username/Documents/ObsidianVault）に設定する；
4. 装飾テーマと配信チャネルを選択し、保存ボタンをクリックすると、専用デジタル出版社が即座に起動します！
