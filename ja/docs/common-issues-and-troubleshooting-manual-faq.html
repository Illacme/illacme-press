❓ よくある質問とトラブルシューティングマニュアル (FAQ)

本マニュアルでは、クリエイターが初めてのご利用から日常の出版作業に至るまでの頻出疑問と自己修復方法を整理しました。

🔌 ポートとサービスの計画

システムはデフォルトで以下の 4 つの標準ポートを使用します。他のアプリケーションとの競合がないことを確認してください：

ポート 役割の説明
43210 🔒 単一インスタンスプロセスロック：バックグラウンドでの重複起動を防ぎ、フィンガープリント台帳の破損を防止します
43212 🔌 API 制御ゲートウェイ：FastAPI バックエンドサービスおよびガバナンスセンターフロントエンドのホスト用
43211 🧙 初期化ガイド：初回設定用のガイダンスポート
43213 🌐 ローカルプレビューサービス：同期完了後に埋め込まれた静的サイトプレビューサーバー

❓ よくある質問への回答

Q1: デフォルトブランドとカスタムブランドの違いは何ですか？

A: デフォルトブランド（imprints/default）はシステムの公式展示ウィンドウです。デフォルトブランドかつデフォルト Sovereign テーマを使用している場合、システムは自動的に全量のプロフェッショナル版機能をアンロックし、ユーザーがシステム全体を完全に体験できるよう支援します。一方、新しいカスタム出版ブランドを作成すると、機能はコミュニティ版と商業ライセンスの計画に従います。

Q2: 原稿を変更しても AI トークンが再消費されないのはなぜですか？

A: システムには段落レベルのシャドウキャッシュ (BlockShadowCache) が組み込まれています。同期ごとに、ドキュメント内の各段落に対してフィンガープリント計算が行われ、変更されていない段落はローカルキャッシュから秒単位で読み取られます。実際に変更が発生した段落のみが AI 翻訳呼び出しを起動します。

Q3: キャッシュをクリアするか、フルリコンパイルを強制するにはどうすればよいですか？

A:
- コマンドライン: python3 plenipes.py --sync --force を実行して強制的に再編成します。
- ガバナンスセンター: 「基本設定」→「ストレージアダプター」に進み、「🧹 フルキャッシュクリア (GC) を今すぐ実行」をクリックします。

Q4: ローカルモデル（Ollama / LMStudio）で 400 エラーが発生したり、フリーズしたりした場合はどうすればよいですか？

A:
1. ローカルモデルサービスが起動しているか確認してください（例：LMStudio サービスで Local Server がオンになっている場合）。
2. 管理センターで max_tokens の値を適切に増大させてください（推奨は $\ge 4096$）。これにより、ローカルモデルの思考プロセス（Thinking Process）出力に必要なスペースを確保できます。

🆘 より多くのサポートを求める場合

リストされていない異常が発生した場合は、管理センターのサイドバーで「コントロールタワー (Tower)」と「ヘルスレーダー」を介してリアルタイムに診断を行ってください。または、GitHub で Issue を提出してください。
