🏷️ ブランド管理と複数サイト (Imprint)

Illacme Plenipes では、各出版プロジェクトは独立した「出版ブランド (Imprint)」です。本ガイドでは、多ブランドアーキテクチャを活用して、複数サイト、複数ライブラリ、および複数チャネルの絶対的な物理的隔離管理を実現する方法を詳しく解説します。

🏛️ 1. 「出版ブランド (Imprint)」とは？

クリエイターが複数の分野でコンテンツを運営する場合（例：個人技術ブログ、学術研究コラム、企業製品ドキュメント、ライフスタイル・トラベル随筆など）、従来の投稿ツールでは、複数の独立したプログラムをデプロイする必要があるか、あるいは同一データベース内で混在して混乱が生じるという課題があります。

Illacme Plenipes の多ブランドアーキテクチャ：
- 物理的隔離ストレージ：各ブランドは専用ディレクトリ imprints/{brand}/ を有し、独立した設定（config.imprint.yaml）、履歴帳簿（usage_ledger.json）、および同期状態を管理します。
- 独立原稿ライブラリ：ブランド A は /Vaults/TechDocs にバインドでき、ブランド B は /Vaults/DailyLife にバインドできます。
- 独立装飾テーマ：技術サイトには Docusaurus または Starlight を採用し、個人ブログには Sovereign サイバー風を採用できます。
- 独立配信マトリクス：技術記事は GitHub Pages と Dev.to に同期され、随筆記事は WeChat 公式アカウントと Substack に同期されます。

🚀 2. ブランドの作成と切り替え方法

方式一：ガバナンスセンターでの可視化操作

  1. ブラウザを開き、ガバナンスセンター http://127.0.0.1:43212/dashboard/ にアクセスします。
  2. 【ブランドインプリントとモード】→【ブランド管理 (imprints)】に移動します。
  3. 「➕ 新規出版ブランド」ボタンをクリックし、ブランドコード（例：tech_weekly）と表示名を入力します。
  4. このブランドのライブラリパス、テーマスタイル、および配信認証情報を設定します。
  5. 「アクティブ化して切り替え」をクリックすると、システムがミリ秒単位で現在のワークスペースをホットスワップします！

方式二：コマンドラインによる高速操作

# 1. 唤醒出版引擎
python3 plenipes.py

# 2. 在交互菜单中选择 [1] 切换出版品牌，或使用参数指定启动：
python3 plenipes.py --imprint tech_weekly --sync

🛡️ 3. デフォルトブランド (Default Imprint) の特殊な位置づけ

  • 即開き展示ウィンドウ：システム標準で用意された imprints/default は、公式の標準テンプレートです。
  • 全機能体験特権：default ブランドにあり、かつ Sovereign テーマがアクティブな場合、システムはデフォルトで全量のプロフェッショナル版機能をアンロックします。
  • 推奨プラクティス：default をシステム機能の実験場として維持し、生産レベルの実際のライブラリは新規に作成した専用ブランドに格納することを推奨します。
