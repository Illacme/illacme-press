⚡ クリエイター向け 5 分間超高速スタートガイド

Illacme Plenipes のご利用を歓迎いたします！以下の 5 つの簡単な手順に従うだけで、創作から全世界への配信までを一連の流れとして数分で体験できます。

🛠️ ステップ 1：グローバル出版エンジンの起動

ターミナルで以下のコマンドを実行してシステムを起動してください：

# 启动出版引擎与治理中心
python3 plenipes.py

ターミナルはエレガントな ASCII アート製の出版バッジを出力し、自動的に Web API コントロールゲートウェイ（ポート 43212）とガバナンスセンターを起動します。

🎛️ ステップ 2：ガバナンスダッシュボードへのアクセス

ブラウザを開き、以下のアドレスにアクセスしてください：
👉 http://127.0.0.1:43212/dashboard/

ガバナンスセンターでは、以下の機能を直感的に体験できます：
1. 基本設定と運用管理：ブランドのアイデンティティの確認、ストレージアダプターの設定、および計算リソースキャッシュのクリアを管理するハブ。
2. ブランド装飾とモード切替：ブランドの切り替え、テーマの設定、および出版モード（ベーシック / エンハンスト / グローバル）の選択。
3. 言語翻訳とガバナンス：多言語マトリックスの設定、ブロックレベルのフィルタリングルール、および用語辞書の管理。
4. 配信ルートと URL パス：フォルダーと URL パスのマッピングマトリックスの設定。

💡 デフォルトのブランド（Illacme Press）は、すべての高度なプロフェッショナル版機能がデフォルトで解放されています。すべての設定項目を自由に試してみてください！

✍️ ステップ 3：ローカル・バレットで原稿を作成する

原稿は ./vault フォルダに安全に保存されます。お好みの Markdown エディタ（Obsidian など）をご利用ください：

  • ./vault/Blog/ 下に新しいファイル my-note.md を作成する
  • 標準的な Markdown タイトルと本文を入力する
---
title: 我的第一篇主权笔记
date: 2026-08-16
tags: [HelloWorld, Note]
---

# 🚀 记录我的最新思考

这是我在 Illacme Plenipes 中撰写的第一篇原稿！

🚀 ステップ 4：ワンクリックで全域配信と翻訳

以下のいずれかの方法で配信をトリガーします：
1. GUI：ガバナンスセンターの右上隅にある 🚀 ワンクリック全域配信 ボタンをクリックします。
2. コマンドライン：python3 plenipes.py --sync を実行して、ワンショットフル同期を実行します。

システムは自動的に以下を実行します：
- 増分パグメントスライシングとハッシュ計算（変更なし部分はゼロトークン消費）
- 計算力センターによる多言語推敲と翻訳
- AI SEO 構造化メタデータ抽出
- 静的サイト HTML アセットレンダリング

🌐 ステップ 5：ローカルプレビューで出版成果を確認

同期完了後、ローカルプレビューサービスにアクセスします：
👉 http://127.0.0.1:43213/

Sovereign サイバーテーマで装飾されたモダンなサイトが表示され、中英両語切り替え、動的目次、リアルタイム検索、レスポンシブレイアウトが備わっています！
