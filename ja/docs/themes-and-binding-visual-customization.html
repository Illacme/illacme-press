🎨 テーマとバインディング（装飾）

Illacme Plenipes では、同一の原稿ライブラリを、異なるフレームワークスタイルのモダンな静的サイトとして自由に装飾できます。

🎭 六大 SSG テーママトリックス

テーマ名 核心技術 適用シナリオとビジュアルスタイル
Sovereign (Default) ネイティブ HTML5 / CSS3 / ES Modules デフォルトフラッグシップサイバーモーフィズム、ダークネオン、ミニマルテクノロジー、ゼロ Node.js 依存の高速直接出力
Docusaurus React / Meta Docusaurus v3 大規模多言語技術ドキュメントライブラリ、ナレッジセンター、API デベロッパーポータル
Starlight Astro / Tailwind CSS 超高速軽量技術ドキュメント、モダンミニマルレイアウト、完璧な SEO 構造
VitePress Vue 3 / Vite 洗練されたクリーンな技術ライティング、超高速ビルドと開発体験
Nextra Next.js / React モダンブログとドキュメント統合型サイト、極めて柔軟性が高い
Hugo Go / Hugo 極めて高い同時接続を処理する巨大ライブラリのミリ秒単位の超高速ビルド

✨ デフォルト Sovereign テーマの特徴

Sovereign テーマはシステムのネイティブフラッグシップ装飾です：

  1. 赛博毛玻璃 (Glassmorphism)：高档半透明磨砂质感与动态呼吸霓虹投影。
  2. 零编译直出：无需经过繁琐的 Node.js npm build 编译链，Python 核心直接毫秒级合成全功能纯静态 HTML。
  3. 多语言一键切换：原生顶部下拉菜单实时无刷新路由对齐。
  4. 即时物理搜索：基于内存倒排索引的本地纯前端极速全文检索。
  5. 动态目录与阅读进度条：右侧动态高亮 TOC 与顶部呼吸式滚动进度。

🛠️ テーマオプションのカスタマイズ (Theme Options)

themes/default/theme.options.json またはガバナンスダッシュボードで視覚パラメータを微調整できます：

{
  "site_name": "Illacme Press",
  "accent_color": "#00f5ff",
  "font_family": "Outfit, sans-serif",
  "enable_glassmorphism": true,
  "enable_dark_mode": true,
  "hero_title": "Illacme Press",
  "hero_subtitle": "您的全球私人出版社。从灵感到全渠道分发，一键触达。"
}
