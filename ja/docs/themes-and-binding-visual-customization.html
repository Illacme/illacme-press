#テーマ、SSG、UI、デザイン

🎨 テーマと装飾のカスタマイズ（Themes & Binding）

Illacme Plenipes において、同一の原稿ライブラリを自由に異なるフレームワークスタイルのモダンな静的サイトとして装飾できます。

🎭 主要な SSG テーマの 6 つのマトリックス

テーマ名 核心技術 適用シナリオとビジュアルスタイル
Sovereign (Default) ネイティブ HTML5 / CSS3 / ES Modules デフォルトフラッグシップサイバーモーフィズム、ダークネオン、ミニマルテクノロジー、Node.js 依存なしの高速直接出力
Docusaurus React / Meta Docusaurus v3 大規模多言語技術ドキュメントライブラリ、知識センター、API デベロッパーポータル
Starlight Astro / Tailwind CSS 超高速軽量技術ドキュメント、モダンミニマルレイアウト、完璧な SEO 構造
VitePress Vue 3 / Vite 洗練された清潔な技術ライティング、超高速ビルドと開発体験
Nextra Next.js / React モダンなブログとドキュメント統合型サイト、非常に柔軟性が高い
Hugo Go / Hugo 極めて高い同時接続を処理する巨大ライブラリのミリ秒単位の超高速ビルド

✨ デフォルト Sovereign テーマの特徴

Sovereign テーマはシステムのネイティブフラッグシップ装飾です：

  1. Cyber Glassmorphism（サイバー毛玻璃）：高級感のある半透明マット質感と、動的に呼吸するネオンプロジェクション。
  2. ゼロコンパイル出力：煩雑な Node.js npm build コンパイルチェーンを介さず、Python コアが直接ミリ秒単位の速度でフル機能の純粋な静的 HTML を合成します。
  3. マルチ言語ワンクリック切り替え：ネイティブのトップドロップダウンメニューによるリアルタイム無刷新ルート同期。
  4. 即時物理検索：メモリ逆インデックスに基づく、ローカル純粋なフロントエンドでの超高速フルテキスト検索。
  5. 動的目次と読進バー：右側の動的ハイライト付き TOC と、上部の呼吸式スクロール進行度表示。

🛠️ テーマオプションのカスタマイズ (Theme Options)

themes/default/theme.options.json またはガバナンスダッシュボードで視覚パラメータを微調整できます：

{
  "site_name": "Illacme Press",
  "accent_color": "#00f5ff",
  "font_family": "Outfit, sans-serif",
  "enable_glassmorphism": true,
  "enable_dark_mode": true,
  "hero_title": "Illacme Press",
  "hero_subtitle": "您的全球私人出版社。从灵感到全渠道分发，一键触达。"
}
