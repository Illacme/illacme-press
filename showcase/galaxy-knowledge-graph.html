🛠️ 核心引擎与视觉交互

1. 🔗 智能双向链接转译器 (WikiLink Resolver)

  • 创作者在 Markdown 中直接使用 [文章标题](../../文章标题.html) 或 [自定义别名](../../文章标题.html)；
  • 适配器在编译为各个装帧主题（Sovereign / Universal / Docusaurus / VitePress 等）时，会自动推导目标页面与当前页面的深度层级，并无缝渲染为标准的相对超链接与锚点跳转。

2. 🌌 治理中心与读者端全息星系图谱

  • 治理中心宏观驾驶舱：提供全局 2D/3D 动态拓扑星系图，实时观测各分类、文档与孤岛笔记的连通密度；
  • 读者端沉浸式漫游：读者在阅读任意长文时，可在右侧或悬浮面板中直接探索当前文章关联的上下游引用网络，一键跳转漫游。

3. 🧬 链路拓扑自愈与断链修复 (Link Healing)

  • 当创作者在文库中重命名某个文件或调整目录结构时，系统的索引引擎会根据别名（Aliases）与 Slug 映射机制自动完成双向链接关系重定向，彻底告别 404 断链烦恼。
